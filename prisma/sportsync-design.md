# Sportsync Design System & Zámer
- **Zámer:** B2B prezentácia pre športoviská. Riešime zrušené rezervácie (chýba 4. hráč) a neobsadené hodiny bez provízií.
- **Farby:** Dark Mode pozadie `#121212`, karty `#1F1F1F` alebo `#262626` so zaoblením `rounded-2xl`.
- **Akcentová farba:** Koralová oranžová `#FF5722` (pre tlačidlá a žiarivé efekty).
- **Typografia:** Biely text nadpisov, sivé metadáta `text-gray-400`[cite: 2].
